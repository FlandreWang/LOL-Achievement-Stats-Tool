# 英雄列表内容优化 - 需求文档

## 1. 背景与目标

当前英雄列表模式（HeroListCard）的角色标签和成就进度都放在展开区域内，用户必须点击展开才能看到这些信息。列表模式有足够的水平空间，角色标签完全可以展示在缩略状态中。同时，英雄维度的列表缺少成就进度展示，用户无法直观了解每个英雄的成就完成情况。

## 2. 功能概述

优化英雄列表卡片的内容布局：角色标签移至缩略区展示，新增缩略区总体成就进度条和展开区逐项成就进度。

## 3. 功能详情

### 3.1 角色标签移至缩略区

- **用户故事**：As a 用户查看英雄列表，I want 直接在列表行中看到角色标签，So that 无需展开即可识别英雄角色定位
- **详细描述**：将角色标签（mage, fighter 等）从展开区域移到缩略区域，在英雄称号右侧水平排列展示
- **验收标准**：
  - [ ] 角色标签在缩略状态下可见，位于英雄称号右侧水平排列
  - [ ] 角色标签样式与现有展开区内一致（pill 形状，bg-lol-primary/10）
  - [ ] 英雄无 roles 时隐藏角色标签区域
  - [ ] 展开区域内不再重复显示角色标签

### 3.2 缩略区总体成就进度

- **用户故事**：As a 用户查看英雄列表，I want 在缩略状态看到每个英雄的成就完成进度，So that 快速了解各英雄的成就完成情况
- **详细描述**：在缩略区域（角色标签右侧或下方）展示一个简洁的成就进度条，显示已完成数/总数
- **数据来源**：`recordStore.records[heroId]` 统计已完成数量，`achievementStore.achievements.length` 为总数
- **验收标准**：
  - [ ] 缩略区展示进度条和 "已完成数/总数" 文字
  - [ ] 全部完成时进度条变为金色
  - [ ] 无成就记录时显示 "0/N"

### 3.3 展开区逐项成就进度

- **用户故事**：As a 用户展开英雄列表项，I want 看到该英雄每个成就的完成状态，So that 了解具体哪些成就已完成、哪些未完成
- **详细描述**：展开区域展示该英雄每个成就的名称和完成状态（已完成/未完成），按成就列表顺序排列
- **数据来源**：遍历 `achievementStore.achievements`，通过 `recordStore.getRecord(heroId, achId)` 获取每个成就的完成状态
- **验收标准**：
  - [ ] 展开区列出所有成就，显示名称和完成状态图标
  - [ ] 已完成的成就显示勾选标记和完成日期
  - [ ] 未完成的成就显示灰色文字
  - [ ] 展开区内容较多时可滚动（调整 max-h 限制）

## 4. 边界与异常

- 英雄无 roles 数组或为空数组：隐藏角色标签区域
- 英雄无任何成就记录：进度条显示 0/N，展开区全部显示未完成
- 成就数量较多（>20）：展开区设置合理的 max-height 并允许滚动
- 角色标签过长：自动换行（flex-wrap）

## 5. 非功能需求

- 无额外 API 调用，所有数据来自已有 store
- 展开/折叠动画保持现有 300ms 过渡效果

## 6. 优先级

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 角色标签移至缩略区 | P0 | 简单模板调整 |
| 缩略区总体成就进度 | P0 | 核心信息展示 |
| 展开区逐项成就进度 | P1 | 详细信息补充 |
