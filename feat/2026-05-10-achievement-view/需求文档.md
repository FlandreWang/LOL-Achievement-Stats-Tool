# 成就维度视图 - 需求文档

## 1. 背景与目标

当前主页仅以英雄维度展示数据（英雄卡片网格），用户可以浏览每个英雄的成就完成进度。但当用户想从成就角度出发，查看某个成就在所有英雄中的完成情况时，缺乏对应的视图。例如用户想知道"五杀"这个成就还有哪些英雄没完成，目前需要逐个点开英雄详情才能确认，效率很低。

本需求在主页增加"成就维度"视图，让用户可以快速筛选某个成就，查看整体进度和逐个英雄的完成状态，并支持快速搜索定位特定英雄。

## 2. 功能概述

主页增加视图切换功能（英雄维度 / 成就维度），成就维度下可选择一个成就，展示该成就在所有英雄上的完成进度，并支持快速搜索英雄。

## 3. 功能详情

### 3.1 视图切换

- **用户故事**：As a 用户，I want 在主页切换英雄维度和成就维度视图，So that 我可以从不同角度查看数据
- **详细描述**：主页顶部（搜索栏附近）增加视图切换控件，支持在"英雄"和"成就两种维度间切换。切换后页面内容区域切换为对应视图。默认选中"英雄"维度，保持现有行为不变。
- **验收标准**：
  - [ ] 主页存在可见的视图切换控件
  - [ ] 切换到"英雄"维度时，显示现有的英雄卡片网格（行为不变）
  - [ ] 切换到"成就"维度时，显示成就选择器和对应的英雄列表
  - [ ] 切换状态在页面刷新后保持（可选，优先级低）

### 3.2 成就选择器

- **用户故事**：As a 用户，I want 在成就维度下选择一个成就，So that 我可以查看该成就的完成情况
- **详细描述**：成就维度视图顶部展示一个成就选择器（下拉列表或标签组），列出所有已定义的成就。选择一个成就后，下方展示该成就的完成进度和英雄列表。默认选中第一个成就。
- **验收标准**：
  - [ ] 成就选择器展示所有已定义的成就名称
  - [ ] 选择某个成就后，下方内容更新为该成就的数据
  - [ ] 无成就时显示空状态提示，引导用户去成就管理页创建
  - [ ] 默认选中第一个成就

### 3.3 成就整体进度

- **用户故事**：As a 用户，I want 看到选中成就的整体完成进度，So that 我可以快速了解完成情况
- **详细描述**：在成就选择器下方展示一个进度条，显示"已完成英雄数 / 总英雄数"，与现有 AchievementStats 组件风格一致。
- **验收标准**：
  - [ ] 进度条正确反映已完成英雄数占总英雄数的比例
  - [ ] 显示具体的数字（如 "12 / 170"）
  - [ ] 100% 完成时进度条变为金色/特殊样式

### 3.4 英雄完成状态列表

- **用户故事**：As a 用户，I want 看到每个英雄对该成就的完成状态，So that 我可以知道哪些已完成、哪些未完成
- **详细描述**：以网格形式展示所有英雄卡片，每张卡片需体现该成就的完成状态（已完成/未完成）。已完成的英雄排在前面，未完成的排在后面。卡片可复用现有 HeroCard 组件或创建新组件，需包含：英雄头像、名称、完成状态标识。点击卡片可跳转到英雄详情页。
- **验收标准**：
  - [ ] 所有英雄以网格形式展示
  - [ ] 每张卡片明确标识该成就是否已完成
  - [ ] 已完成英雄默认排在前面
  - [ ] 点击卡片可跳转到英雄详情页
  - [ ] 响应式布局（复用现有的断点策略）

### 3.5 成就维度搜索

- **用户故事**：As a 用户，I want 在成就维度下快速搜索英雄，So that 我可以快速确认某一个成就在某一个英雄上有没有完成
- **详细描述**：成就维度视图中提供搜索框，搜索逻辑与现有英雄搜索相同（中文名/拼音/英文名模糊搜索）。搜索结果实时过滤英雄列表，同时保留完成状态的标识。
- **验收标准**：
  - [ ] 搜索框支持中文名、拼音、英文名搜索
  - [ ] 搜索结果实时过滤，保留完成状态标识
  - [ ] 清空搜索后恢复完整列表
  - [ ] 搜索无结果时显示空状态

## 4. 边界与异常

| 场景 | 处理方式 |
|------|----------|
| 尚未定义任何成就 | 成就维度视图显示空状态，提示用户去"成就管理"创建成就 |
| 选中成就无任何记录 | 所有英雄显示为"未完成"状态 |
| 搜索无结果 | 显示空状态提示 |
| 成就数量很多导致选择器溢出 | 选择器支持滚动 |
| 成就名称过长 | 截断显示，hover 时显示完整名称 |
| 英雄数据加载中 | 显示骨架屏 |

## 5. 非功能需求

- 搜索性能：复用现有 Fuse.js + pinyin-pro 引擎，170+ 英雄列表过滤应在 50ms 内完成
- 响应式：复用现有断点策略（2-6 列网格）
- 兼容性：支持现有主题（亮色/暗色）
- 数据一致性：成就维度视图的数据来源于现有 stores，无需新增 localStorage key

## 6. 优先级

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 视图切换控件 | P0 | 入口，必须先有 |
| 成就选择器 | P0 | 核心交互 |
| 成就整体进度 | P0 | 核心信息展示 |
| 英雄完成状态列表 | P0 | 核心内容 |
| 成就维度搜索 | P0 | 用户明确要求 |
| 完成/未完成排序 | P1 | 提升体验 |
| 点击跳转详情 | P1 | 复用现有路由 |
| 空状态处理 | P1 | 边界场景 |
