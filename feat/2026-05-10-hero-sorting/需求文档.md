# 英雄列表排序功能 - 需求文档

## 1. 背景与目标

当前英雄列表只支持按 hero_id 数字升序排序，用户无法按自己的喜好浏览英雄。本需求将添加排序功能，支持多种排序方式，提升用户体验。

## 2. 功能概述

在英雄tab中添加排序选择器，支持多种排序方式，并记住用户的排序偏好。

## 3. 功能详情

### 3.1 排序选择器

- **用户故事**：As a 用户，I want to 在英雄tab中选择排序方式，So that 我可以按自己的喜好浏览英雄
- **详细描述**：
  - 在搜索栏和布局切换按钮之间添加排序选择器
  - 使用下拉菜单形式
  - 显示当前排序方式
- **验收标准**：
  - [ ] 排序选择器显示在正确位置
  - [ ] 点击展开下拉菜单
  - [ ] 显示当前排序方式

### 3.2 排序方式

- **用户故事**：As a 用户，I want to 支持多种排序方式，So that 我可以快速找到想要的英雄
- **详细描述**：

| 排序方式 | 说明 | 排序字段 |
|----------|------|----------|
| 默认排序 | hero_id 升序 | heroId |
| 英文名 A→Z | alias 升序 | alias |
| 英文名 Z→A | alias 降序 | alias |
| 拼音名 A→Z | name 的拼音升序 | name (pinyin) |
| 拼音名 Z→A | name 的拼音降序 | name (pinyin) |
| 成就多→少 | 已完成成就数降序 | completedCount |
| 成就少→多 | 已完成成就数升序 | completedCount |

- **验收标准**：
  - [ ] 支持所有排序方式
  - [ ] 排序结果正确
  - [ ] 切换排序时列表立即更新

### 3.3 排序偏好记忆

- **用户故事**：As a 用户，I want to 我的排序选择被记住，So that 下次打开时不需要重新选择
- **详细描述**：
  - 使用 localStorage 存储排序偏好
  - 下次打开时自动应用
- **验收标准**：
  - [ ] 排序偏好被保存
  - [ ] 刷新页面后排序保持

## 4. 边界与异常

- **搜索时排序**：搜索结果应保持当前排序方式
- **成就数量排序**：需要关联成就记录计算，可能影响性能
- **拼音排序**：使用 pinyin-pro 库进行拼音转换

## 5. 非功能需求

- **性能**：排序操作应在 100ms 内完成
- **兼容性**：支持所有现代浏览器

## 6. 优先级

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 排序选择器 | P0 | 核心功能 |
| 排序方式 | P0 | 核心功能 |
| 偏好记忆 | P1 | 优化体验 |
