## 5. 建议调整

### 调整 1：简化展开内容

**原计划**：展开后显示角色标签、成就进度条、各成就完成状态列表

**调整为**：
- 英雄tab：展开显示角色标签 + 成就进度条（已完成/总数）
- 成就tab：展开显示角色标签 + 当前选中成就的完成状态 + 完成时间

### 调整 2：提取布局偏好 composable

**新增任务**：创建 `src/composables/useLayoutPreference.js`

```javascript
export function useLayoutPreference(key) {
  const layout = ref('grid')

  onMounted(() => {
    const saved = localStorage.getItem(key)
    if (saved === 'grid' || saved === 'list') {
      layout.value = saved
    }
  })

  watch(layout, (val) => {
    localStorage.setItem(key, val)
  })

  return layout
}
```

### 调整 3：补充交互细节

**补充**：
- 名称/头像点击 → 跳转详情页
- 展开按钮点击 → 展开/折叠
- 需要在 HeroListCard 中区分两个点击区域
