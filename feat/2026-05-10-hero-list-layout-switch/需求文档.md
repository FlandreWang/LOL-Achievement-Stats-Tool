# 英雄列表布局切换 - 需求文档

## 1. 背景与目标

当前应用的英雄tab和成就tab都采用大头像网格布局（HeroGrid），这种布局直观但信息密度较低。用户需要进入详情页才能查看英雄的成就进度。

本需求新增一种横向卡片列表布局，允许用户在网格视图和列表视图之间切换。列表视图采用折叠/展开模式，用户可以在不离开列表页的情况下快速预览英雄的成就详情。

## 2. 功能概述

在英雄tab和成就tab中新增横向卡片列表布局，支持网格/列表切换，横向卡片支持点击展开查看详情。

## 3. 功能详情

### 3.1 布局切换功能

- **用户故事**：As a 用户，I want to 在英雄tab和成就tab中切换网格和列表布局，So that 我可以根据自己的喜好选择查看方式
- **详细描述**：
  - 在英雄tab和成就tab的搜索栏旁边添加布局切换按钮
  - 提供两种布局模式：网格视图（Grid）和列表视图（List）
  - 切换按钮使用图标表示：网格图标（Grid3x3）和列表图标（List）
  - 当前激活的布局模式高亮显示
- **验收标准**：
  - [ ] 英雄tab中显示布局切换按钮
  - [ ] 成就tab中显示布局切换按钮
  - [ ] 点击切换按钮可切换布局模式
  - [ ] 当前布局模式高亮显示

### 3.2 横向卡片组件

- **用户故事**：As a 用户，I want to 以横向卡片形式查看英雄列表，So that 我可以在紧凑的布局中浏览更多英雄
- **详细描述**：
  - 新建 HeroListCard 组件，采用横向布局
  - 左侧显示英雄头像（较小尺寸，如 48x48 或 64x64）
  - 右侧显示英雄名称、称号
  - 整行可点击，点击触发展开/折叠
  - 悬停时显示视觉反馈
- **验收标准**：
  - [ ] 横向卡片正确显示英雄头像
  - [ ] 横向卡片正确显示英雄名称和称号
  - [ ] 卡片有悬停效果
  - [ ] 点击卡片触发展开/折叠

### 3.3 折叠/展开功能

- **用户故事**：As a 用户，I want to 点击横向卡片展开查看详情，So that 我可以在不离开列表页的情况下预览成就进度
- **详细描述**：
  - 卡片默认折叠状态，只显示头像、名称、称号
  - 点击卡片展开，显示更多信息：
    - 英雄角色标签（roles）
    - 成就完成进度（已完成/总数）
    - 各成就的完成状态列表
  - 展开时显示展开/折叠图标指示器
  - 使用平滑的展开/折叠动画
  - 允许多个卡片同时展开
- **验收标准**：
  - [ ] 卡片默认折叠，只显示基本信息
  - [ ] 点击展开显示详细信息
  - [ ] 展开状态显示成就进度
  - [ ] 有展开/折叠动画效果
  - [ ] 展开图标正确指示状态

### 3.4 成就tab的横向卡片适配

- **用户故事**：As a 用户，I want to 在成就tab中也使用横向卡片布局，So that 我可以统一的浏览体验
- **详细描述**：
  - 成就tab的横向卡片复用 HeroListCard 组件
  - 卡片额外显示该英雄在当前选中成就下的完成状态
  - 已完成的英雄卡片显示完成标记
  - 支持搜索过滤
- **验收标准**：
  - [ ] 成就tab中可切换到列表视图
  - [ ] 列表视图显示英雄的成就完成状态
  - [ ] 搜索功能在列表视图下正常工作

### 3.5 布局偏好记忆

- **用户故事**：As a 用户，I want to 我的布局选择被记住，So that 下次打开时不需要重新切换
- **详细描述**：
  - 使用 localStorage 存储用户的布局偏好
  - 英雄tab和成就tab的布局偏好分别存储
  - 下次打开时自动应用上次的布局选择
- **验收标准**：
  - [ ] 切换布局后刷新页面，布局保持不变
  - [ ] 英雄tab和成就tab的布局偏好独立存储

## 4. 边界与异常

- **搜索结果为空**：布局切换按钮仍然显示，空状态提示适配两种布局
- **展开状态下切换布局**：切换到网格视图时，展开状态丢失，切换回列表视图时重新折叠
- **移动端适配**：横向卡片在小屏幕下头像和文字合理排列，展开内容自动换行
- **大量英雄**：列表视图使用虚拟滚动或分页，避免性能问题（如英雄数量超过100个）

## 5. 非功能需求

- **性能**：列表渲染性能与现有网格视图相当
- **动画**：展开/折叠动画流畅，不卡顿（建议使用 CSS transition）
- **响应式**：在移动端和桌面端都有良好的展示效果
- **无障碍**：展开/折叠按钮有适当的 aria 属性
