# 液面球体进度展示 - 需求文档

## 1. 背景与目标

当前 `AchievementProgress` 组件的进度环中心数字（百分比）没有背景，视觉上不够突出。需要在中心数字下方添加一个圆形球体，内部带有液面波动动效，液面高度随进度百分比动态变化，使进度展示更加直观酷炫。

## 2. 功能概述

在进度环中心数字下方添加圆形液面球体背景，液面高度对应进度百分比，带有持续波动的波浪动画，完成时变为金色发光效果。

## 3. 功能详情

### 3.1 液面球体背景
- **用户故事**：As a 用户，我希望进度数字有一个圆形球体背景，So that 数字不会显得悬浮，视觉层次更清晰
- **详细描述**：在 `.progress-ring-content` 中心区域添加一个圆形容器，内部填充与进度对应的液面
- **验收标准**：
  - [ ] 球体为正圆形，位于进度环中心
  - [ ] 球体有半透明背景和微妙的边框
  - [ ] 数字浮于液面之上，清晰可读

### 3.2 液面波动动效
- **用户故事**：As a 用户，我希望液面有持续的波浪波动效果，So that 进度展示更加生动有趣
- **详细描述**：使用 SVG 波浪路径 + CSS 动画实现液面波动，波浪持续水平移动
- **验收标准**：
  - [ ] 波浪持续平滑波动，无卡顿
  - [ ] 液面高度随百分比线性变化（0% = 底部，100% = 充满）
  - [ ] 波浪有前后两层，营造立体感

### 3.3 完成状态特效
- **用户故事**：As a 用户，我希望 100% 完成时液面变为金色并发光，So that 完成状态有明显的视觉反馈
- **详细描述**：完成时液面颜色变为金色，添加发光效果
- **验收标准**：
  - [ ] 完成时液面颜色变为金色
  - [ ] 球体有金色发光光晕

## 4. 边界与异常

- 0% 时液面完全在底部，球体为空
- 100% 时液面充满球体
- total 为 0 时显示空球体

## 5. 非功能需求

- 纯 CSS/SVG 实现，无额外依赖
- 动画性能良好，不引起页面卡顿
- 兼容亮色/暗色主题

## 6. 优先级

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 液面球体背景 | P0 | 核心视觉需求 |
| 液面波动动效 | P0 | 核心动效需求 |
| 完成状态特效 | P1 | 增强体验 |
