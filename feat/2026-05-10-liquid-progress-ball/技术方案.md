# 液面球体进度展示 - 技术方案

## 1. 技术选型

- **液面波浪**：SVG `<path>` + CSS `@keyframes` 动画（两层波浪营造立体感）
- **液面容器**：CSS `border-radius: 50%` + `overflow: hidden` 裁剪为圆形
- **液面高度**：CSS `transform: translateY()` 由百分比计算，带 `transition` 平滑过渡
- **颜色方案**：使用 CSS 变量，完成时切换为金色

## 2. 架构设计

```
AchievementProgress.vue
├── SVG 进度环（已有）
├── 液面球体容器（新增）
│   ├── 波浪层 1（SVG path，慢速）
│   ├── 波浪层 2（SVG path，快速，透明度更低）
│   └── 数字覆盖层（已有，z-index 在波浪之上）
└── 右侧信息区（已有）
```

## 3. 数据结构

无需新增数据结构，复用现有 props：
- `completed: Number` — 已完成数
- `total: Number` — 总数
- 计算属性 `percent` — 百分比

## 4. 接口设计

组件对外接口不变，仅修改内部视觉实现。

## 5. 核心逻辑

### 液面高度计算
```
液面偏移 = 球体高度 × (1 - percent / 100)
当 percent = 0 时，液面完全在底部（偏移 = 球体高度）
当 percent = 100 时，液面充满（偏移 = 0）
```

### 波浪动画
使用 SVG path 绘制正弦曲线，通过 CSS `@keyframes` 水平平移：
```
M0,10 C20,5 30,15 50,10 C70,5 80,15 100,10 L100,50 L0,50 Z
```
- 动画 1：`translateX` 从 0 到 -50%，持续 3s（慢波）
- 动画 2：`translateX` 从 -50% 到 0，持续 2.5s（快波）

## 7. 风险与对策

| 风险 | 对策 |
|------|------|
| 波浪动画性能 | 使用 `transform` 动画，触发 GPU 加速 |
| 圆形裁剪溢出 | 使用 `overflow: hidden` + `border-radius: 50%` |
| 数字被波浪遮挡 | 数字层 `z-index` 高于波浪层 |
