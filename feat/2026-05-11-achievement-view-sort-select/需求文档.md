# 成就维度页面排序与多选 - 需求文档

## 1. 背景与目标

成就维度页面（AchievementView）目前存在两个体验问题：
- 英雄列表排序方式硬编码为"已完成优先"，用户无法自定义排序
- 无法批量操作英雄的完成状态，只能逐个点击

本次需求为成就维度页面添加排序能力和多选批量操作能力，提升用户操作效率。

## 2. 功能概述

为成就维度页面添加可配置的排序功能和多选批量操作功能。

## 3. 功能详情

### 3.1 成就维度排序

- **用户故事**：As a 用户，I want 在成就维度页面选择不同的排序方式，So that 我可以按自己偏好的顺序浏览英雄列表
- **详细描述**：
  - 在成就维度页面的搜索栏旁添加排序下拉选择器
  - 排序选项包括：
    - 已完成优先（当前默认行为）
    - 未完成优先（新默认值）
    - 中文名 A→Z / Z→A
    - 英文名 A→Z / Z→A
    - 称号 A→Z / Z→A
  - 排序偏好持久化到 localStorage
- **验收标准**：
  - [ ] 成就维度页面显示排序下拉选择器
  - [ ] 默认排序为"未完成优先"
  - [ ] 所有排序选项正确生效
  - [ ] 排序偏好在页面刷新后保持

### 3.2 多选与批量操作

- **用户故事**：As a 用户，I want 在成就维度页面多选英雄并批量更改完成状态，So that 我可以一次性处理多个英雄而无需逐个点击
- **详细描述**：
  - 每个英雄卡片（网格和列表模式）前添加复选框
  - 提供"全选"/"取消全选"按钮
  - 选中后底部出现操作栏，支持"批量标记完成"和"批量标记未完成"
  - 批量操作使用 API 逐个调用 toggle（复用现有接口）
- **验收标准**：
  - [ ] 每个英雄卡片显示复选框
  - [ ] 支持全选和取消全选
  - [ ] 选中后显示批量操作栏
  - [ ] 批量标记完成/未完成功能正常
  - [ ] 操作完成后清除选中状态

## 4. 边界与异常

- 搜索过滤后，全选应仅选中当前可见的英雄
- 批量操作过程中显示加载状态
- 空列表时隐藏多选控件

## 5. 非功能需求

- 复用现有 HeroSortSelect 组件样式模式
- 多选状态不持久化（页面刷新后清除）

## 6. 优先级

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 成就维度排序 | P0 | 核心体验改善 |
| 默认排序改为未完成优先 | P0 | 与排序功能同步实现 |
| 多选与批量操作 | P1 | 效率提升功能 |
