## 5. 建议调整

### 调整 1：MySQL 安装策略

**原计划**：直接安装 MySQL

**调整为**：
1. 先检查系统是否已安装 MySQL
2. 如果已安装，验证连接是否正常
3. 如果未安装，提供以下选项：
   - 使用 Docker（推荐，最简单）
   - 使用安装包
   - 使用包管理器（如 Homebrew、apt）

### 调整 2：保留离线模式

**补充**：
- 当后端不可用时，自动回退到 localStorage
- 在前端显示连接状态提示
- 支持纯前端模式（无后端）

### 调整 3：数据迁移策略

**补充任务**：
- 在设置页添加"从 localStorage 迁移"按钮
- 迁移前备份现有数据
- 迁移完成后提示用户

### 调整 4：健康检查接口

**新增**：
- GET `/api/health` - 返回服务状态和数据库连接状态

## 6. 总结

开发计划基本可行，建议进行以下调整后执行：

1. 先检查 MySQL 是否已安装，提供多种安装方式
2. 保留离线模式，确保无后端时也能基本使用
3. 添加数据迁移功能
4. 添加健康检查接口
