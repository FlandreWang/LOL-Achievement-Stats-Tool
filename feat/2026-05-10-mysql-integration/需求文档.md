# MySQL 数据库集成 - 需求文档

## 1. 背景与目标

当前项目是纯前端应用，使用浏览器 localStorage 存储数据，通过直接调用腾讯官方 API 获取英雄数据。这种方案存在以下问题：

1. **加载速度慢**：每次打开页面都需要请求腾讯 API
2. **数据安全性**：localStorage 容量有限，且用户清除浏览器数据会丢失所有记录
3. **扩展性差**：无法支持多设备同步、数据备份等高级功能

本需求将引入 MySQL 数据库，新增后端 API 服务，实现数据持久化存储，提升加载速度和数据安全性。

## 2. 功能概述

新增 Node.js 后端服务，接入 MySQL 数据库，实现英雄数据缓存（30天）、成就数据存储、手动数据更新等功能。

## 3. 功能详情

### 3.1 MySQL 安装和配置

- **用户故事**：As a 开发者，I want to 安装并配置 MySQL，So that 项目可以使用数据库存储数据
- **详细描述**：
  - 安装 MySQL 8.x 数据库
  - 配置数据库连接参数（host、port、user、password、database）
  - 创建数据库和表结构
  - 编写初始化脚本
- **验收标准**：
  - [ ] MySQL 服务正常运行
  - [ ] 可以通过命令行或客户端连接数据库
  - [ ] 数据库表结构创建成功

### 3.2 后端 API 服务

- **用户故事**：As a 开发者，I want to 创建后端 API 服务，So that 前端可以通过 API 访问数据库
- **详细描述**：
  - 使用 Node.js + Express 创建后端服务
  - 实现 RESTful API 接口
  - 配置 CORS 跨域支持
  - 实现错误处理和日志记录
- **验收标准**：
  - [ ] 后端服务正常启动
  - [ ] API 接口可正常访问
  - [ ] 跨域配置正确

### 3.3 英雄数据缓存

- **用户故事**：As a 用户，I want to 英雄数据被缓存到数据库，So that 打开页面时加载更快
- **详细描述**：
  - 英雄数据存储到 MySQL 数据库
  - 缓存有效期为 30 天
  - 优先从数据库读取数据
  - 缓存过期时自动从腾讯 API 更新
  - 记录最后更新时间
- **验收标准**：
  - [ ] 英雄数据成功存储到数据库
  - [ ] 打开页面时优先从数据库加载
  - [ ] 缓存过期后自动更新
  - [ ] 记录并显示最后更新时间

### 3.4 手动全量更新

- **用户故事**：As a 用户，I want to 手动触发数据更新，So that 我可以获取最新的英雄数据
- **详细描述**：
  - 在设置页添加"更新英雄数据"按钮
  - 点击按钮触发全量数据更新
  - 显示更新进度和状态
  - 更新完成后显示新的拉取时间
  - 支持更新失败时的错误提示
- **验收标准**：
  - [ ] 设置页显示更新按钮
  - [ ] 点击按钮触发数据更新
  - [ ] 显示更新进度或状态
  - [ ] 更新完成后显示新的拉取时间

### 3.5 成就数据存储

- **用户故事**：As a 用户，I want to 成就数据存储在数据库中，So that 数据更安全可靠
- **详细描述**：
  - 成就定义存储到数据库
  - 成就记录（英雄完成状态）存储到数据库
  - 与英雄数据分开存储
  - 支持从 localStorage 迁移数据
- **验收标准**：
  - [ ] 成就定义成功存储到数据库
  - [ ] 成就记录成功存储到数据库
  - [ ] 成就数据与英雄数据分开存储
  - [ ] 支持数据迁移

### 3.6 英雄详情页增强

- **用户故事**：As a 用户，I want to 在英雄详情页看到英文称号和英文名，So that 我可以了解更多英雄信息
- **详细描述**：
  - 在英雄详情页显示英文名（alias）
  - 在英雄详情页显示英文称号
  - 调整页面布局以展示更多信息
- **验收标准**：
  - [ ] 英雄详情页显示英文名
  - [ ] 英雄详情页显示英文称号
  - [ ] 页面布局合理美观

## 4. 边界与异常

- **MySQL 连接失败**：服务启动时检查连接，失败时给出明确错误提示
- **数据库表不存在**：首次启动时自动创建表结构
- **缓存过期**：自动从腾讯 API 更新，失败时使用过期数据
- **网络请求失败**：保留现有数据，给出错误提示
- **数据迁移失败**：保留 localStorage 数据，给出迁移失败提示

## 5. 非功能需求

- **性能**：数据库查询响应时间 < 100ms
- **可靠性**：服务异常时不影响前端基本功能
- **兼容性**：支持 MySQL 8.x
- **安全性**：数据库连接信息不暴露在前端代码中
