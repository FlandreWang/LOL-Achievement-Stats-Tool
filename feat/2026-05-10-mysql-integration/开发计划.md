# MySQL 数据库集成 - 开发计划

## 任务清单

### 阶段一：环境搭建

- [x] 1. 检查并安装 MySQL 数据库
  - 检查系统是否已安装 MySQL
  - 如未安装，使用包管理器安装 MySQL 8.x
  - 启动 MySQL 服务
  - 配置 root 密码

- [x] 2. 创建数据库和用户
  - 创建 `lolachievements` 数据库
  - 创建专用数据库用户
  - 授予权限

- [x] 3. 创建后端项目结构
  - 创建 `server/` 目录
  - 创建 `server/package.json`
  - 安装依赖：express, mysql2, cors, dotenv

- [x] 4. 编写数据库初始化脚本
  - 创建 `server/scripts/init-db.sql`
  - 定义 heroes 表结构
  - 定义 achievements 表结构
  - 定义 records 表结构

### 阶段二：后端 API 开发

- [x] 5. 创建数据库配置模块
  - 创建 `server/config/db.js`
  - 使用 mysql2 创建连接池
  - 从环境变量读取配置

- [x] 6. 创建 Express 服务入口
  - 创建 `server/index.js`
  - 配置 CORS 跨域
  - 配置 JSON 解析
  - 注册路由
  - 启动服务

- [x] 7. 实现英雄数据服务
  - 创建 `server/services/heroService.js`
  - 实现从数据库获取英雄数据
  - 实现从腾讯 API 获取数据
  - 实现缓存过期判断（30天）
  - 实现数据更新逻辑

- [x] 8. 实现英雄数据 API 路由
  - 创建 `server/routes/heroes.js`
  - GET `/api/heroes` - 获取所有英雄
  - GET `/api/heroes/:id` - 获取单个英雄
  - POST `/api/heroes/refresh` - 强制刷新
  - GET `/api/heroes/status` - 获取缓存状态

- [x] 9. 实现成就定义 API 路由
  - 创建 `server/routes/achievements.js`
  - GET `/api/achievements` - 获取所有成就
  - POST `/api/achievements` - 创建成就
  - PUT `/api/achievements/:id` - 更新成就
  - DELETE `/api/achievements/:id` - 删除成就

- [x] 10. 实现成就记录 API 路由
  - 创建 `server/routes/records.js`
  - GET `/api/records` - 获取所有记录
  - GET `/api/records/:heroId` - 获取英雄记录
  - POST `/api/records/toggle` - 切换完成状态
  - PUT `/api/records/note` - 更新备注
