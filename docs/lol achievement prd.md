## 📋 项目概述

### 项目名称
**LOL Hero Achievement Tracker**（英雄联盟英雄成就追踪器）

### 项目目标
打造一个本地化的网页应用，帮助玩家追踪和管理自己在每位英雄上完成的个人成就（如"五杀"、"单杀对线英雄"、"满装备通关"等），所有成就项目由用户自定义。

### 项目背景
- 当前日期：2026 年 5 月 10 日
- 数据来源：英雄联盟官方数据接口（拳头 / 腾讯）
- 部署方式：纯本地运行，无需服务器

---

## 🎯 核心功能需求

### 1. 英雄数据获取（爬虫模块）

#### 1.1 数据源
- **首选**：腾讯官方接口  
  `https://game.gtimg.cn/images/lol/act/img/js/heroList/hero_list.js`
- **备选**：Riot Data Dragon  
  `https://ddragon.leagueoflegends.com/cdn/<最新版本>/data/zh_CN/champion.json`

#### 1.2 需爬取字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `heroId` | 英雄唯一 ID | `103` |
| `name` | 中文名 | `阿狸` |
| `title` | 中文称号 | `九尾妖狐` |
| `alias` | 英文别名（用于头像 URL） | `Ahri` |
| `avatar` | 头像 URL | `https://game.gtimg.cn/images/lol/act/img/champion/Ahri.png` |
| `roles` | 定位标签（可选） | `["mage","assassin"]` |

#### 1.3 爬取策略
- 一次性爬取并写入本地 JSON 文件 `heroes.json`
- 提供"刷新数据"按钮，手动触发更新
- 失败时显示错误提示，并使用本地缓存

---

### 2. 本地数据存储（文件型数据库）

#### 2.1 文件结构
```
/data
  ├── heroes.json          # 英雄列表（爬虫产出，只读）
  ├── achievements.json    # 用户自定义成就项目定义
  └── records.json         # 每个英雄完成成就的记录
```

#### 2.2 数据格式

**heroes.json**
```json
[
  {
    "heroId": "103",
    "name": "阿狸",
    "title": "九尾妖狐",
    "alias": "Ahri",
    "avatar": "https://game.gtimg.cn/images/lol/act/img/champion/Ahri.png"
  }
]
```

**achievements.json**（用户自定义成就模板）
```json
[
  {
    "id": "ach_001",
    "name": "五杀",
    "description": "一局游戏内完成五杀",
    "createdAt": "2026-05-10T15:00:00+08:00"
  },
  {
    "id": "ach_002",
    "name": "20连胜",
    "description": "",
    "createdAt": "2026-05-10T15:01:00+08:00"
  }
]
```

**records.json**（成就完成记录）
```json
{
  "103": {
    "ach_001": { "completed": true, "completedAt": "2026-05-10T15:30:00+08:00", "note": "对线辛德拉" },
    "ach_002": { "completed": false }
  }
}
```

#### 2.3 持久化方式（二选一）
- **方式 A（推荐，纯前端）**：使用浏览器 `localStorage` + 「导出 / 导入 JSON」按钮
- **方式 B（带后端）**：Node.js + Express，用 `fs` 读写 JSON 文件

---

### 3. 模糊搜索功能

#### 3.1 搜索范围
- 中文名（`name`）
- 中文称号（`title`）
- 英文别名（`alias`）
- 拼音 / 拼音首字母（如输入 `aili` 或 `al` 可匹配 "阿狸"）

#### 3.2 搜索特性
- **实时搜索**：输入即过滤，无需点击按钮（防抖 150 ms）
- **大小写不敏感**
- **模糊匹配**：支持子串匹配（如 "妖狐" → 阿狸）
- **拼音支持**：使用 `pinyin-pro` 库
- **空输入**：显示全部英雄

#### 3.3 推荐技术
- 轻量方案：原生 `String.includes()` + `pinyin-pro`
- 进阶方案：`Fuse.js`（带评分排序）

---

### 4. 成就管理功能

#### 4.1 成就项目管理（全局）
- ➕ **新增成就**：填写名称（必填）、描述（选填）
- ✏️ **编辑成就**：修改名称、描述
- 🗑️ **删除成就**：二次确认；删除时同步清理所有英雄上该成就的记录
- 📋 **成就列表页**：查看所有自定义成就

#### 4.2 英雄成就记录（针对单个英雄）
- 进入英雄详情页后，展示**所有成就项目**列表
- 每项支持：
  - ☑ 切换"已完成 / 未完成"
  - 📝 添加备注（如"用神装通关"、"对线某英雄完成"）
  - ⏱ 自动记录完成时间
- 显示完成进度，例如 `已完成 12 / 30 个成就`

#### 4.3 全局统计（可选增强）
- 仪表盘展示：
  - 已完成全成就的英雄数
  - 每个成就的完成率（多少英雄完成过）
  - 最近完成的成就时间线

## 🎨 界面设计需求

### 页面结构

```
┌─────────────────────────────────────────────┐
│  Logo  [搜索框 🔍]    [成就管理] [导入/导出]  │  ← 顶部导航
├─────────────────────────────────────────────┤
│                                             │
│   [英雄网格 - 头像 + 名称 + 称号]             │  ← 首页
│   ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐                 │
│   │  │ │  │ │  │ │  │ │  │                 │
│   └──┘ └──┘ └──┘ └──┘ └──┘                 │
│   阿狸  亚索  劫   寒冰  EZ                  │
│   九尾  疾风  影流  弓箭  探险                │
│                                             │
│   完成度徽章：3/10 ●●●○○○○○○○                │
└─────────────────────────────────────────────┘
```

### 页面清单
1. **首页**：英雄网格 + 搜索框 + 每个英雄的完成度小徽章
2. **英雄详情页**：英雄信息 + 成就清单（勾选 + 备注）
3. **成就管理页**：增删改查自定义成就
4. **设置页**：刷新英雄数据、导入 / 导出数据、清空记录

### 视觉风格
- **主题**：暗色调（贴合 LOL 风格），主色 `#0AC8B9`（破败王者青）/ `#C8AA6E`（金色）
- **响应式**：支持 PC（4-6 列）和移动端（2-3 列）
- **图标库**：Lucide 或 Tabler Icons

## ✅ 验收标准

1. 打开页面后能看到全部 LOL 英雄（截至 2026.5）的头像、中文名、称号
2. 在搜索框输入中文 / 拼音 / 英文均能模糊匹配出英雄
3. 用户可自定义新增成就项，并对每个英雄独立勾选完成情况
4. 关闭浏览器后再次打开，所有自定义数据保留
5. 支持一键导出全部数据为 JSON 文件，并能重新导入恢复
6. 删除成就项时会清理对应记录，无脏数据残留
