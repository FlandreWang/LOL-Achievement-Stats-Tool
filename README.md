# LOL 英雄成就追踪器

追踪和管理你在每位英雄联盟英雄上完成的个人成就。

## 启动

```bash
npm install
npm run dev
```

打开浏览器访问终端中显示的地址。

## 构建

```bash
npm run build
```

产物在 `dist/` 目录，可直接部署到任意静态托管。

## 功能

- 172 位英雄数据（来源腾讯官方接口）
- 模糊搜索：支持中文、拼音、英文
- 自定义成就管理：新增 / 编辑 / 删除
- 英雄成就勾选：切换完成状态、添加备注
- 完成进度追踪
- 数据导入 / 导出（JSON 格式备份）
- 主题切换：跟随系统 / 亮色 / 暗色

## 数据备份

在 **设置** 页面点击 **导出数据** 即可下载 JSON 备份文件。需要恢复时点击 **导入数据** 选择备份文件即可。
